## Approach

Each case answers the brief's questions in order, with:
- **one diagram**, with the stack named on each component
- **the reasoning** behind each choice
- **trade-offs and risks**: what each choice costs, and how it's mitigated
- **assumptions** where the brief is open, what changes if they're wrong, and the questions I'd ask on day 1

Code examples: CI/CD templates for Case 5 in [case-5-dataops-dbt-airflow/templates](case-5-dataops-dbt-airflow/templates/), and illustrative Terraform for Case 2 in [.cloud/terraform/case-study-2](.cloud/terraform/case-study-2/).
